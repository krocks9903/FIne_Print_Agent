## How each session was run (M3 script)

| Script section | What we did |
|---|---|
| **§0 Checklist** | Laptop ready, sample lease on Desktop, session ID assigned, recording offer noted as declined |
| **§1 Opening (~2 min)** | Class project framing · no right/wrong · **not legal advice** · ~20 minutes · stop anytime · wait for yes |
| **§2 Warm-up (~3 min)** | Three questions: last document · how they check it · past fee/renewal surprise |
| **§3 Task brief (~1 min)** | “About to sign tonight” · find money costs / traps · think aloud · we stay quiet |
| **§4 During task (8–10 min)** | Silent unless ~20s stuck · then **one** script prompt only · no defending UI |
| **§5 After the scan (~5 min)** | Six follow-ups exactly as written (what it did · surprise · quote trust · use again · never use · 1–5 likelihood) |
| **§6 Closing (~1 min)** | Thanks · anonymous quotes · questions · fill template while fresh |
| **Optional (~5 min)** | Email/renewal reminder question from the script — only if they still had time |

Facilitator don’ts observed: no mid-task apologies, no “the AI should have caught X,” no teammate interruptions, no SSNs / account numbers / full names in notes.

## Blurb for the M4 PDF

> Following the M3 user-testing script, we ran two external pilots on 18 Nov 2026 (FGCU campus Dunkin’ Donuts intercepts, ~20–25 minutes each, sample lease, notes-only).
